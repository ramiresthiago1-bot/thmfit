THM FIT
Sistema de gestão para academia

========================================
SOBRE O PROJETO
========================================

O THM FIT é um sistema de gestão desenvolvido para uma academia de musculação.

O projeto utiliza:

- HTML
- CSS
- JavaScript
- Supabase
- Git / GitHub

O sistema está sendo desenvolvido passo a passo.

========================================
COMO ABRIR O PROJETO
========================================

1. Abra a pasta do projeto no VS Code.
2. Instale a extensão Live Server.
3. Abra o arquivo index.html com "Open with Live Server".
4. Entre com o usuário criado em:
   Supabase > Authentication > Users
5. Também existe o botão "Abrir demonstração local" para testes.

OBSERVAÇÃO IMPORTANTE
========================================

O desenvolvedor do projeto não é programador profissional.

O desenvolvimento está sendo realizado passo a passo com auxílio do ChatGPT.

Sempre que possível, fornecer os arquivos completos para substituição usando:

Ctrl+A -> Delete -> Ctrl+V

Evitar instruções que exijam procurar e substituir pequenas partes de códigos muito grandes.

========================================
REGRA DE CONTINUIDADE
========================================

Antes de iniciar uma nova etapa:

1. Conferir o status do Git.
2. Confirmar que o projeto está sincronizado com origin/main.
3. Fazer alterações.
4. Testar no navegador.
5. Fazer commit.
6. Fazer push.
7. Confirmar "main -> main".

Nunca considerar uma etapa concluída sem testar o sistema.
